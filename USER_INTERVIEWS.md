# User Interviews — SpendSmart AI

## Methodology

Conducted 5 informal interviews with potential users during the build week (May 7–13, 2025). Participants were engineering managers, solo founders, and developers at small companies.

---

## Interview 1 — Solo Founder, SaaS startup

**Current stack:** ChatGPT Plus, Cursor Pro, Claude Pro  
**Monthly spend:** ~$60/month  
**Key quote:** "I honestly don't know if I need all three. I use ChatGPT out of habit but I think Claude is better for writing."  
**Insight:** Users maintain subscriptions out of habit, not active value assessment. A tool that surfaces "you're using this less" would be compelling.

---

## Interview 2 — Engineering Manager, 12-person team

**Current stack:** GitHub Copilot Business (12 seats), ChatGPT Team (8 seats)  
**Monthly spend:** ~$470/month  
**Key quote:** "We signed up for Copilot Enterprise by mistake. I didn't realise Business had everything we needed."  
**Insight:** Plan confusion is very real. People don't read plan comparison pages carefully. The "downgrade" recommendation is the highest-value output of this tool.

---

## Interview 3 — Developer, agency

**Current stack:** Cursor Pro, Windsurf Pro  
**Monthly spend:** $35/month  
**Key quote:** "I have both because I couldn't decide. I should probably just pick one."  
**Insight:** Overlap/redundancy between similar tools (Cursor + Windsurf) is a common waste pattern not yet covered by the engine. Good future feature.

---

## Interview 4 — CTO, 25-person startup

**Current stack:** OpenAI API, Anthropic API, GitHub Copilot Enterprise  
**Monthly spend:** "A lot. Maybe $2,000/month but I'm not sure."  
**Key quote:** "The API costs are unpredictable. I'd pay for something that helps me forecast and cap them."  
**Insight:** API spend auditing (not just SaaS plans) is a bigger pain point for technical teams. Future version should handle API token spend.

---

## Interview 5 — Product Manager, mid-size company

**Current stack:** ChatGPT Team, Notion AI, Gemini for Workspace  
**Monthly spend:** "HR manages it. I don't actually know."  
**Key quote:** "If this could generate a report I could send to my manager to justify the spend, that would be useful."  
**Insight:** The shareable audit URL directly addresses this. The PDF export would be an even better fit for this persona.

---

## Key Themes

1. **Habit-based subscriptions** — people don't actively reassess what they're paying for
2. **Plan confusion** — Business vs Enterprise vs Team tier differences are opaque
3. **Tool overlap** — maintaining competing tools (Cursor + Windsurf, ChatGPT + Claude) is common
4. **API cost unpredictability** — separate problem from SaaS auditing, but high pain
5. **Shareability matters** — the report needs to be something you can send upward
